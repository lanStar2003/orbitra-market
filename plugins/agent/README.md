# Agent 包

每个领域一个 Agent：它的说明、技能和工具清单

共 9 个。

| 名称 | 版本 | 核心 | 安装包 | 说明 |
|---|---|---|---|---|
| [通用 Agent](general) | 1.0.1 | **核心** | 自带 | 没有对口的 Agent 时先把事办完，并记下能力缺口 |
| [自进化 Agent](evolve) | 1.1.3 | **核心** | 自带 | 分析运行数据提出优化建议；按用户的需求改 Agent 的做事方式，或直接改 Orbitra 自己的代码（测过、复核过再等用户批准发布） |
| [编码 Agent](code) | 1.0.2 | 可选 | 自带 | 读写代码、复现问题、修复和重构 |
| [研究 Agent](research) | 1.0.0 | 可选 | 自带 | 检索、读论文和文档，给出可核验的出处 |
| [写作 Agent](writing) | 1.0.0 | 可选 | 自带 | 学习笔记、文章、周报；按用户的模板和语气写 |
| [运维 Agent](ops) | 1.0.1 | 可选 | 自带 | 发布、部署、巡检服务器；生产环境的每次变更都要用户批准 |
| [测试 Agent](test) | 1.0.1 | 可选 | 自带 | 写测试、跑回归和端到端测试，给出能复现的失败报告 |
| [视频 Agent](video) | 1.0.0 | 可选 | 自带 | 讲解视频：脚本、分镜、Remotion 工程和渲染 |
| [日程 Agent](calendar) | 1.0.1 | 可选 | 自带 | 日历、提醒、邮件摘要；替用户排时间，不替用户回复别人 |
