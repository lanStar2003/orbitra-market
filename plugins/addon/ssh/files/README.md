# SSH 终端

连接服务器的完整客户端：终端、文件管理、快捷命令、无代理监控、端口转发、密钥和已知主机管理。左侧导航"终端"。

内核直接用 [ssh2](https://github.com/mscdex/ssh2)（打包进 `dist/`）建连接，不依赖系统的 ssh。设计和接口约定在 `docs/设计-SSH.md`。

## 怎么用

1. 在主机栏新建一台主机，选认证方式：密码、私钥（已存的密钥或文件路径）、本机 ssh-agent、键盘交互（两步验证）。第一次连接要确认指纹。
2. 点主机打开终端；已经开着就切过去，再开一个点"+"。页面刷新、切走，终端都不断，输出能回放（每个会话 512 KB）。
3. 断线后按 1、2、4、8、16、30 秒重试（设置里能关）；认证失败或手动关闭不重试。
4. 服务器关了密码登录但开着键盘交互时，只有一个密码提示就自动答存的密码，其它提示（比如两步验证码）转给页面。同一台主机的终端、文件、监控、转发共用一条连接，两步验证只答一次。
5. 旧服务器握手失败时，在主机的"高级"里打开"兼容旧服务器"。

转发的 `auto` 开关：这台主机连上时自动打开，不会自己去连主机。

## 配置

**设置 › 插件配置** 或 **插件页**：字号、终端主题、回滚行数、心跳间隔、选中即复制、右键粘贴、断线重连、跟随目录、记录历史。

## 安全

- 密码、私钥、口令用 `createSealer(keys, 'addon-ssh')` 封存在 `core.db`，不离开内核：接口只回 `hasPassword`、`hasPassphrase`，日志和事件里没有。
- 没见过的指纹要主人确认；指纹变了默认拒绝，要主人明确选"信任新指纹"；Agent 的连接从不提问，没确认过就报错。
- 本机文件接口（`/local/list`、`copy-from-local`、`copy-to-local`）只接受本机请求，经网关来的一律 403。
- 转发默认绑 `127.0.0.1`，绑到别的地址要在请求里写 `allowOutside: true`。

## Agent

`ssh_servers`、`ssh_run` 走 `/api/addons/ssh/proc/*`，每次执行记入 `sshx_audit`，页面的"记录"面板能看。

## 开发

- 构建：`node scripts/addons/build.mjs ssh`
- 测试：`node --test "addons/ssh/test/*.test.js"`，全部对 `test/helpers/server.js` 起的本地 `ssh2.Server`（127.0.0.1、随机端口），不连真实服务器。
